# Cascade Internal Portal - Application

This folder will hold the source code for the Cascade Internal Portal,
the custom internal web application used as the target application for
this IAM project.

The application will be integrated with PingFederate using SAML 2.0 and
OpenID Connect, as described in the root [README.md](../README.md).

Application source code, setup instructions, and configuration details
will be added here as the project progresses.
